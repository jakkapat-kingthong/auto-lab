# ReToken: One Token to Improve Vision-Language Models for Visual Retrieval

> ArXiv | 2026-08-02 | paper 2

Long visual context poses a challenge for vision-language models: performance degrades as the number of distractors grows, and processing all tokens at once is computationally infeasible under GPU memory constraints.
