# KPPax: preprocess differentiable kinetic ODE for machine learning in atmospheric chemistry

Atmospheric chemical mechanisms are commonly distributed in the language of the Kinetic PreProcessor (KPP), which generates efficient Fortran or C code but does not fit into the differentiable programming frameworks in which machine-learning models are developed.
